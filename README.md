# RedBite — Vibe Engineering Assignment

## Project
Responsive Food Delivery Website using:
- HTML
- CSS
- Vanilla JavaScript
- Red, Black & White visual theme

## Required features implemented
- 8 food menu items
- Add to Cart
- Cart counter
- Increase / decrease quantity
- Automatic subtotal, delivery fee and total price
- Checkout form
- Place Order interaction
- Mobile responsive design
- Category filter
- Accessible buttons and form labels

## AI Agent Practice
The assignment asks for an AI-assisted workflow:
Analyze → Plan → Implement → Test → Review → Fix

Use this project as the implementation result. For your submission screenshots, take screenshots from the AI tools you actually use (GitHub Copilot Agent, Cursor Agent, or OpenAI Codex) while asking them to analyze, improve, test and fix the project.

## Suggested prompts
1. "Analyze this food delivery website against the assignment requirements and list missing features."
2. "Review the responsive CSS and identify layout problems on 320px mobile screens."
3. "Test the cart logic for add, remove, quantity changes and total calculation. Find bugs."
4. "Review accessibility and form validation and suggest fixes."
5. "Implement the approved fixes, then re-test the complete user flow."
