# AI Agent Rules

## Workflow
Always follow:
Analyze → Plan → Implement → Test → Review → Fix

## Rules
1. Do not change the visual theme away from red, black and white without approval.
2. Use semantic HTML and accessible labels.
3. Use Vanilla JavaScript only; no framework is required.
4. Keep cart calculations in one source of truth.
5. Test mobile layouts at narrow widths.
6. Test add, increase, decrease, checkout and order placement.
7. Review generated code before final submission.
8. Do not claim a test passed unless it was actually run.
